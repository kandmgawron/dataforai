Bedrock vs AgentCore

Amazon Bedrock

  • Model access — Claude, Llama, Titan, Cohere
  • RAG (Retrieval-Augmented Generation)
  • Prompt engineering and guardrails
  • Single-turn inference, knowledge bases
Example: A customer asks "what's your returns policy for sale items?" — Bedrock retrieves the right policy doc and generates a precise answer. One question, one answer, done.

Amazon AgentCore

  • Multi-step orchestration
  • Tool use and system integration
  • Workflow chaining and decision logic
  • Agent identity, memory, session management
Example: An agent checks order status, finds a delivery exception, looks up the refund policy, drafts a resolution email, and queues it for approval. Five steps, no human in the loop until sign-off.
🔑 Bedrock is the brain. AgentCore is the hands. You need both for anything beyond simple Q&A.

Confidential

This is the core distinction, and it's worth getting right before the labs.

Bedrock is where the models live. It's a managed service that gives you access to foundation models — Claude from Anthropic, Meta's Llama, Amazon's own Titan, Cohere for embeddings. You use it for:

  • Generating text responses from prompts
  • RAG: attaching a knowledge base (your docs, your data) so the model answers from your content, not its training data
  • Guardrails: content filtering, topic blocking, PII redaction

The key mental model: Bedrock handles single-turn interactions. You ask, it answers. It can be sophisticated (RAG, multi-doc retrieval), but it's fundamentally request-response.

AgentCore is the orchestration layer. It takes Bedrock's inference capability and chains it into multi-step workflows. An agent can:

  • Call APIs (your internal systems, third-party services)
  • Make decisions based on intermediate results
  • Maintain session state across multiple turns
  • Hand off between sub-agents for different domains

The example on the right is deliberate — that five-step workflow is exactly the kind of thing EposNow could build for CS ticket resolution or order management. But it depends on Bedrock underneath for the actual language understanding.

In the labs this afternoon, you'll work with both. Bedrock labs first (model access, RAG setup), then AgentCore labs (building an agent that uses tools).
